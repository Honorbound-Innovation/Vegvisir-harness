# Evals and Verification

Vegvisir's deterministic evals cover memory isolation, secret rejection, approvals, tool bounds, prompt-injection defenses, golden command cases, artifacts, context, subagents, policy explanations, providers, and autonomy levels.

Commands:

- `/eval all`
- `/eval artifacts`
- `/eval context`
- `/eval subagents`
- `/eval approvals`
- `/eval providers`
- `/eval autonomy`
- `/verify all`
