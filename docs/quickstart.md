# Quickstart

1. Install Vegvisir.
2. Run `vegvisir setup --guided`.
3. Configure provider credentials through HBSE; do not paste plaintext credentials into chat.
4. Run `vegvisir setup --check` and `vegvisir verify all`.
5. Start Vegvisir and send a small safe task.
6. Inspect `/runs show latest`, `/context last`, `/memory used-this-turn`, and `/trace`.
